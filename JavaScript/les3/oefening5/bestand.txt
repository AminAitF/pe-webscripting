Het probleem is dat je twee verschillende modules in hetzelfde bestand hebt gezet. In Node.js werkt require('./util/InputError') alleen als InputError in een apart bestand staat.

Nu staat je code zo in één file:

module.exports = class Vec {...}

'use strict';
module.exports = class InputError extends Error {}

Maar:

1️⃣ De tweede module.exports overschrijft de eerste
2️⃣ require('./util/InputError') probeert een ander bestand te laden dat niet bestaat

Wat je hebt:

Vec.js – klasse voor een 2D vector met x en y. Heeft plus(), minus(), length en toString(). Gooit een InputError als je geen nummers meegeeft.
Polyline.js – klasse voor een reeks van Vec's. Je kan er Vec's aan toevoegen met add(), en hij gooit een error als het geen Vec is.
InputError.js – custom error klasse, extends gewoon Error. Simpel maar proper.
app.js – test alles ff uit. Maakt vectors, telt ze op, voegt ze toe aan een Polyline.
